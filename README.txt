HOW TO USE
1. Open index.html in any browser (double-click it). Keep style.css, script.js and the same folder next to it.
2. To put it online, upload the whole folder to any static host (Netlify Drop, GitHub Pages, Cloudflare Pages).

HOW TO EDIT
- Name, email, WhatsApp, Instagram: the CONFIG block at the top of script.js.
- Paintings (title, medium, image file): the WORKS list in script.js. Add a new object and drop the image in this folder.
- Colours and fonts: the variables at the top of style.css.
- Headline and About text: index.html.
